# Documentation Folder

This folder stores the final project documentation, presentation materials, and supporting files for the Plant Disease Detector project.

## Files Included

- `Final_Mitchell_Monepha_ITAI1378.pdf` – Final presentation slides
- `AI_usage_log.md` – Documentation of AI assistance used during the project
- Additional project documentation and notes

## Purpose

The documents in this folder support the final implementation of the Plant Disease Detector system and provide evidence of project planning, organization, and final deliverables.

## Notes

This project was improved from the original midterm proposal into a completed computer vision system capable of classifying plant diseases from leaf images using deep learning techniques.
